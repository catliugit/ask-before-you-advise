# Pilots

Configuration and reference outputs from the pilot runs that shaped the instrument. These are
kept for transparency and are not the live study configuration (`../config.yaml` is).

- `config.spread-pilot.yaml`: the six-scenario spread pilot that set which scenarios admit.
- `config.mini-pilot.yaml`: the car-finance and Lifetime-ISA mini-pilot that validated the new items.
- `codebook_grades.snapshot.json`: the frozen snapshot of the 52 pilot grades, used as a byte-identity guard by the test suite.
